# TreeCarbon EDU

校園樹木碳匯調查 webapp，適合 iPad 與手機現場使用。

## Public Webapp

https://tree-carbon-edu.hsiehpangg.chatgpt.site

## Features

- 內建嘉義縣大南國小樹木清冊範本資料
- 支援手動上傳 CSV、TSV、XLSX、XLS
- 優先讀取 Excel 的「樹木列表」
- 以「樹木種類」與「分類」作為後續辨識與計算資料
- iPad / iPhone 相機、定位、動作感測檢查
- 步驟 2 可開啟 Gemini Live 協助確認植物
- 胸徑 DBH、樹高、CO2e 教學估算
- 本機儲存調查紀錄並匯出 CSV / JSON
- 首頁提供 QR Code，方便 iPhone / iPad 掃描登入

## Local Development

```bash
corepack pnpm install
corepack pnpm dev
```
